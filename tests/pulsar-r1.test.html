Orden de entrega bajo reentrada

Un listener suscrito a s => s.x recibe x = 2 y, desde dentro, escribe x = 3. Cada paso es una invocación del listener en el orden en que ocurrió. La secuencia debe ser monótona: ningún paso puede reportar un valor anterior al del paso previo, y cada prev debe ser el actual del paso anterior.
